# 设计契约 · prompt-engineering-kg 原型站（多轮次适用）

> 性质：**跨轮次的设计契约**。用户第 3 次反馈指出「很多问题都是设计原则未落实」——
> 根因不是某条规则被违反，而是**规则从未被写成可审核的对象**。本件把三轮反馈里的原则
> 固化成带 ID 的条目，每条必须有「机检判据」或「未落实」二者之一，⛔ 不允许第三种状态。
> 用法：每轮开工先读本表 → 声明本轮触碰哪些 R-xx → 收口时逐条复核状态。
>

> **编码成机制**）、新增 **§4 §轮次执行协议**（下一轮照做即对）、§2 新增 **G6–G9**、
> 同批新增判据 **P38 / P39 / P40** 与两个开工必跑探针（`_probe_env.py` / `_probe_channel.py`）。
