### 2.2 技术设计（决策已定，⛔ 不留给执行者再定）

**(a) 图件由数据派生，⛔ 不手绘**（`gen-figs.py` 增一个函数，`FIGS` 由它注入 11 条）：

- fid 命名：`grp-<gid 小写>`（`G00` → `grp-g00`；`GD-N` → `grp-gd-n`）。
- 节点：该组成员；label = `中文短名`（取 `name` 里 `（` 之前的部分，超 12 字截断）`\n(PE-X-NN · 第 L 层)`。
- 边：**内部边**（两端都在组内）= 实线（⛔ 不逐条标注 rel，避免 9 条边时糊成一片）；**跨组边** = 汇聚成一个 `组外接口` stub 节点（虚线、注明「出 K 条 / 入 J 条」）⇒ 11 张图宽度可控。
- 布局：`rankdir=LR` + **按层 `{rank=same}` 分组**（层变成列 ⇒ 宽而矮），⛔ 不用 TB（9 节点的 TB 会撞 600px 高限）。
- 色值：只用 `HEX2VAR` 的 16 个（成员用 `--brand-soft`/`--brand-primary`，stub 用 `--surface-subtle`/`--warning`）；越界 `postprocess` 会 `SystemExit`。
- caption：`「本组内部依赖与对外接口：组内 N 个节点、M 条内部边、K 条跨组边（层 L₁–L₂）」`；★ 「本站自制」由 `figure_html` 自动附在 `figcaption`（P36 ⑤）。
- 规格：**必须过 `gen-figs.check_spec`**（`viewBox.h/viewBox.w × 804 ≤ 600px`）——第 5 轮 `pe-f-04/05` 两次当场被拒，⛔ 不得靠 CSS 缩放掩盖。
- 字形：CJK + 数字 + `₁₂` 之类下标要**逐个过 fontconfig**（P36 ⑥ fail-closed）——★ **建议避开 `₁₂` 这类下标，直接用 `(层 10–21)`**。

**(b) 组页渲染**（`gen-groups.py`）：在 `.read-map` 之后插 `C.figure_html(fid, caption, reveal=1)`（与 `gen-nodes.py` 的位置同一体例）。

**(c) 判据扩作用域**（`gate_prototype.py` 的 P35 ⑧）：

  并把「其余页不强制」写成**显式豁免清单 + 理由**（⛔ 不得靠控制流偶然豁免 —— 那正是本轮 R-23 的成因）。
- 三处声明（docstring / 注释 / CHECKS 标题）改为「**内容承载页（节点页 / 组页）≥1 图**」。
- **新增负例夹具**：把某个组页的 `.fig` 去掉 ⇒ 必须 FAIL（否则新扩的作用域没有可判假性）。

**(d) 契约改写（四处 + 一份登记件，⛔ 同批）**：
1. `DESIGN-CONTRACT.md` §1 **R-07** → 「**内容承载页（节点页 / 组页）≥1 张自制图**；图内联、随主题、带图注与溯源。★ 导航 / 索引 / 交互 / 路径页**不强制**（理由：交互页本身就是图；索引页由 11 组一览表承载；入口页职责是开门；路径页的全局拓扑由交互图承载）」并把「判据」列改为 `P35 ⑧ + P36`。
2. `CONTENT-V2.md` §0 行 3 → 同义改写 + 备注「本条与 §1.1 骨架表以**骨架表**为准」。
3. `CONTENT-V2.md` §1.1 骨架表 → 给**组页**加一列「图件：本组 mini-DAG」；给另三页（索引 / 入口 / 交互 / 路径）加豁免说明。
