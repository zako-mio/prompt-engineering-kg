落地实践迁移运行时

一句话结论

跨运行时迁移的正确动作是重测、重编译并保留回滚点，而不是复制粘贴。

01为什么需要它

同一套提示词与技能从运行时 A 搬到运行时 B 时，能搬走的是结构与判据，搬不走的是效力：工具声明方式、上下文注入方式、思考块回传要求与提示词承载对象都会随运行时与模型代际改变，旧写法可能从有效变成中性甚至有害。

  • 若把迁移当成复制粘贴，这类差异往往不以报错形式出现，而是以难以解释的行为漂移出现，排查成本远高于迁移本身。

适用边界

本节点的教训来自具体运行时与模型代际的实测形态，换运行时或换代际后必须在新环境重新验证；同一运行时内的小版本升级差异通常较小，但仍以重测结果为准。

02机制说明

跨运行时迁移的差异集中在四处。

  • 能力面：prefill 是否仍被接受、思考块是否必须原样回传、工具声明由谁生成；上下文注入：运行时自动加入的环境说明、工具清单与时间戳会与提示词自身的指令竞争；承载方式：提示词放在自己的代码仓库里，还是寄存在运行时的远端对象上；校验入口：判据与确认在何处触发。
  • 因此迁移的动作不是复制粘贴，而是三步：先在新运行时上跑最小复现（同一任务、同一模型、只换运行时），把两侧的完整输入与输出都留下来对比；再把差异逐条归类为能力缺失、隐式注入或写法失效；最后按新能力面重编译提示词与配置，并保留一份可直接切回的旧版本。

03何时该用 / 何时不该用

按场景对照：先看条件，再看该怎么做。
类别场景 / 条件（总结）具体做法（细节）
该用把提示词或技能迁到新运行时之前先跑最小复现，确认差异来自运行时而不是任务本身。
该用升级模型代际时把旧写法逐条重测，判定它仍然有效、已经中性化，还是已经变成有害。
不该用直接套用旧运行时的调优结论能力面与隐式注入都不同，结论必须在新环境重建。
不该用把迁移当成一次性动作运行时与模型会持续升级，迁移清单要随版本复跑。

04实验台

  1. filemarkdown

    查看代码
    # 跨运行时迁移重测清单

- 能力面核对：prefill 是否仍被接受、思考块是否必须原样回传、工具声明由谁生成。
- 最小复现：同一任务、同一模型、只换运行时，两侧的完整输入与输出都要留存。
- 差异归类：逐条标为能力缺失、运行时隐式注入或写法失效，不留下未归类的差异。
- 重编译：按新能力面改写参数与字段，而不是保留旧字段反复重试。
- 回滚点：保留一份可直接切回的旧配置，并写明切换方式。

    预期观察：五节全部填写完成，且每条差异都有归类与处置结论；存在未归类差异时视为未完成。

  2. shellbash

    查看代码
    # 同一任务、同一模型、只换运行时：两侧各跑一次并落盘原始输出
mkdir -p migration/runtime-a migration/runtime-b
python3 run_task.py --runtime a --prompt prompt.md --out migration/runtime-a/out.json
python3 run_task.py --runtime b --prompt prompt.md --out migration/runtime-b/out.json
diff -u migration/runtime-a/out.json migration/runtime-b/out.json | tee migration/diff.txt
cp -r config config.rollback

    预期观察：diff 有输出即说明两侧存在可观测差异，须逐条归类；config.rollback 已生成，可随时切回旧配置。

06术语

术语换模型即失效与重编译　Model Swap Invalidates and Requires Recompilation

界定提示词中的多数经验与具体模型绑定；更换模型后必须重跑评测并重做优化，而不是沿用旧结论。

相关节点—

术语标记敏感度的迁移性　Transferability of Markup Sensitivity

界定对某种标记（如 XML 标签）的响应强度取决于该模型是否针对此类标记做过指令对齐训练，因此同一标记在不同模型上的效果不可假定一致。

相关节点—

术语自适应思考　Adaptive Thinking

界定由模型自行决定思考深度的现行机制，取代手动指定思考 token 预算的旧做法；后者在新一代模型上已返回错误。

相关节点—

07失效模式

  • 把迁移当复制粘贴旧写法在新运行时上静默失效，输出照旧生成，但原有的判据已不再成立。
  • 只对比最终答案、不对比两侧输入运行时隐式注入带来的差异被漏掉，问题被误判成模型能力不足。
  • 沿用旧代际的调优结论已经变成有害的写法被继续保留，质量下降却找不到原因。
  • 迁移后不留回滚点新写法一旦不达标，只能凭记忆重写旧配置，恢复成本高于迁移本身。
